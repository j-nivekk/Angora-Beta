# Angora 1.1.3-beta.3

Thank you for testing Angora. This build refines 1.1.3 for macOS 14 and 15 and tidies how documents are handled: dragging the annotation list into your preferred order now works on older macOS, the document-tab “+” opens an existing PDF rather than an empty one, and File ▸ New is retired — a blank PDF has no place in an editor. It carries forward everything earlier 1.1.3 betas introduced: a hardened undo system, a calmer overlay toolbar, full-length Liquid Glass on macOS 26, an annotation list you can arrange to taste, faithful shape duplication, native inline predictions for comments, and sharper control over your own keyboard shortcuts.

## At a glance

- **No blank documents** — Angora edits PDFs, so **File ▸ New** and **⌘N** are retired and the document-tab **“+”** now opens an existing PDF instead of creating an empty one.
- **Reordering, fixed on macOS 14 and 15** — dragging the annotation list's sort tabs and colour filters now works on older macOS, not only macOS 26.
- **Undo, without the crash** — pressing ⌘Z after adding or editing a comment is safe again, and undo and redo are steadier across the app.
- **A correct Edit menu, even after saving** — **Undo** and **Redo** track the document faithfully and keep working past a save point.
- **Steadier page thumbnails** — a page's thumbnail updates in place instead of flashing when you edit its annotations.
- **A calmer overlay toolbar** — the floating tool palette trades Liquid Glass for a clean, light- and dark-aware fill that never flickers, even over a busy, scrolling page.
- **Liquid Glass, end to end** — on macOS 26 the PDF flows beneath the window chrome and sidebar, with your pages staying centred in the space that remains visible and a refined sidebar to match.
- **An annotation list you can arrange** — drag the sort tabs and colour filters into the order you prefer, and your colour order carries across documents.
- **Shapes that follow your hand** — draw towards an edge and the canvas pans to keep up; duplicate and paste now reproduce a shape faithfully, and Escape abandons a stroke in progress.
- **Smarter comment editing** — Quick Comment and annotation-list comments now support native macOS inline predictions.
- **A toolbar that behaves** — it makes room on a narrow window, and reveals on hover in full screen if you ask it to.
- **Shortcuts, your way** — record custom keys in Settings, with clear handling when a key is already in use.

## No blank documents

Angora edits PDFs — there is no meaningful blank document to create — so this build removes the routes that could make one, while leaving opening and saving untouched.

- **File ▸ New and ⌘N, retired.** The New command is now disabled. **Open**, **Open Recent**, and **Save** are unaffected.
- **The “+” opens, not creates.** With several documents sharing a window, the tab strip's **“+”** button now opens an existing PDF instead of starting a blank one — reliably from the very first click, on every supported version of macOS.

## macOS 14 and 15, squared away

- **Annotation reordering works again.** The drag-to-reorder gestures for the annotation list's sort tabs and colour filters could be unresponsive on macOS 14 and 15; they now respond on every supported version of macOS.

## Stability

This build hardens Angora's undo system and steadies the sidebar thumbnails.

- **No more crash on Undo.** Adding or editing a comment and then pressing ⌘Z could crash Angora. A comment field's own editing history is now kept separate from the document's, so undoing is safe.
- **One dependable history.** Undo and redo are tracked in a single place, removing the rare cases where a ⌘Z could quietly do nothing.
- **The Edit menu, in step.** **Edit ▸ Undo** and **Redo** now reflect the document's real state and keep working after you save — so you can step back past a save point from the menu, not only the keyboard.
- **Undo what you typed.** While a comment field is open, Undo affects your typing in that field rather than the page beneath it.
- **No thumbnail flash.** When you edit annotations on a page, its thumbnail updates in place instead of blanking and redrawing.

## A calmer overlay toolbar

In 1.1.2 we quietened the overlay toolbar's Liquid Glass over busy pages. This release goes further and settles it for good.

- **No more flicker.** Over a scrolling or detail-heavy page, the glass could still recomposite against the moving content and flash the window. The overlay now uses a flat, stable fill — the flicker is gone on every supported version of macOS.
- **It reads in any light.** The fill and its new hairline border are light- and dark-aware, so the palette stays defined whether it floats over a bright page or a dark one.
- **Your opacity, honoured.** The background opacity slider now takes effect in system-colour mode too, not only with a custom colour — dial the palette as solid or as sheer as you like.

## Liquid Glass, end to end

On macOS 26, Angora now follows the system's Liquid Glass conventions across the whole document window.

- **A continuous surface.** The PDF extends beneath the window toolbar and into the sidebar region, removing the hard seam between the sidebar and the page; content flows under the chrome as you scroll and zoom, just as it does in Preview.
- **Always centred where it counts.** Your pages now stay optically centred in the space that remains visible — clear of the sidebar and below the toolbar — rather than drifting behind them. Open, close, or resize the sidebar and the page recentres to match.
- **Cleaner document tabs.** With several documents open in one window, the active tab's soft shadow no longer clips into a hard seam where the title bar meets the full-bleed page.
- **A tidier sidebar.** The annotation list, search, and sidebar hierarchy have been refined for the new chrome, with clearer grouping and spacing.
- **Smoother thumbnails.** The thumbnail rail renders off the main thread and settles as you drag the sidebar wider or narrower, keeping scrolling and resizing fluid.
- **Older macOS, unchanged.** Every refinement is gated to macOS 26; on macOS 14 and 15 the window behaves exactly as before.

## An annotation list you can arrange

The annotation list now bends to how you read, not the other way around.

- **Reorder the sort tabs.** Drag **Page**, **Date**, and **Item** into whatever order suits your workflow; your arrangement is remembered.
- **Reorder — and rank — your colours.** Drag the colour filters to arrange them. Because different documents use different colours, your preferred order is kept as a ranking that follows you from one document to the next, with any new colours falling in neatly behind.
- **The text you marked, front and centre.** Rows now show the page text a highlight or shape actually covers, instead of echoing your comment — so the covered text and your note read as two distinct things.
- **Author names, when you want them.** A new **Show author names in annotation list** toggle (Settings → General, off by default) surfaces each annotation's author alongside it.

## Shapes that follow your hand

- **The canvas keeps up.** When you draw a shape and reach the edge of the view — or press up against the sidebar while zoomed in — the page now pans to follow your cursor, so a single stroke can extend onto content that was off-screen.
- **Faithful duplication.** Copying, pasting, or duplicating a shape now carries its fill, border width, note text, font, and alignment — not just its outline — and keeps the copy on the page. Repeated pastes cascade rather than stacking on the same spot.
- **Step back instantly.** Press Escape mid-draw, move, or resize to abandon the gesture and snap back to where you began, committing nothing.

## A toolbar that makes room

- **Auto-minimising on narrow windows.** When the window becomes too narrow to show the toolbar in full, it tidies itself into its compact state rather than spilling tools into an overflow menu. Widen the window again and it stays as you left it.

## Full screen, your way

- **A new Full Screen Toolbar setting.** Under **Settings → Interface**, choose **Automatic** to keep the native window toolbar in place, or **On Hover** to let it tuck away and reveal as you reach for it.

## Comment editing

- **Native inline predictions.** Quick Comment and annotation-list comment fields now show macOS inline predictions when your language and system settings support them. Suggestions appear in place as you type, accept with Space, and disappear as you keep typing.
- **No change to your flow.** Enter still saves, Escape still cancels, and unsupported languages or disabled predictions simply fall back to normal typing.

## Settings, sharpened

- **Record your own shortcuts.** A new Raycast-style key recorder lets you set custom keyboard shortcuts by simply pressing the keys — and recording a key no longer fires the matching tool on a document open behind Settings.
- **Clear conflict handling.** Assign a key another action already uses and Angora reassigns it for you, removing it from the old action and showing a brief warning — with a one-tap **Undo** if you change your mind.
- **A cleaner colour well.** The custom colour control now opens a single native popover, resolving its previous dual behaviour.
- **A link where you need it.** The Colour Selection Shortcuts note now links straight to the Annotation tab.
- **A faster Annotation tab.** Available fonts are now cached, removing the lag that used to greet you when opening the tab.

## Refinements

- **Quick Comment plays nicely with the overlay toolbar.** With Quick Comment armed, you can now click and drag the floating toolbar instead of having its buttons swallowed by the comment cursor.
- **Steadier Quick Comment.** Disarming Quick Comment no longer mutates state mid-render, clearing a SwiftUI update warning and tightening the tool's behaviour.
- **Sharper Quick Comment, too.** With the full-bleed canvas, Quick Comment now ignores the strip tucked behind the sidebar, so it only ever picks up the annotations you can actually see.
- **Go to Page, per window.** With several documents open, the Go to Page overlay now responds only in its own window.
- **Broader localisation,** including the new full-screen toolbar setting and the shortcut controls.

## Updating

If you are already running Angora, choose **Check for Updates…** and Sparkle will offer 1.1.3 (Smoke Pearl). Otherwise, download the latest `.dmg` from the [Releases page](https://github.com/j-nivekk/Angora-Beta/releases), open it, and drag Angora into your Applications folder.

The Beta is signed with an Apple Development certificate but is **not notarised by Apple**, so macOS Gatekeeper will block it on first launch. You only need to do this once:

- **Recommended.** Control-click **Angora Beta** in Applications → **Open** → **Open**.
- Or, after a blocked attempt, open **System Settings → Privacy & Security** and click **Open Anyway**.
- Or, from Terminal: `xattr -cr /Applications/Angora\ Beta.app`.

- Apple Silicon or Intel
