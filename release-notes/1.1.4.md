# Angora 1.1.4-beta.1

The largest feature set since 1.1.0, mostly about comments: seeing them in the margin, getting them out as Markdown, and formatting them as you type. Also adds palette sharing, keyboard navigation of the annotation list, and macOS 27 support.

## At a glance

- **Margin comment indicators** — a coloured dot beside every marked-up passage carrying a comment. Hover to fan a cluster, click to open one.
- **Dots follow the sidebar filter** — filtered-out comments dim rather than disappear.
- **Export annotations as Markdown** — whole document or current filter, to a file or the clipboard.
- **Copy as Clean Text (⌘⇧C)** — joins wrapped lines, removes hyphenation, normalises ligatures. Plain ⌘C unchanged.
- **⌘B / ⌘I in comment fields** — toggle Markdown emphasis.
- **⌥↑ / ⌥↓** — step through annotations in the sidebar's current order.
- **Palette backup and share** — export tool and Quick Colours as a code or file; import on another Mac.
- **Colour filter clustering** — near-identical colours merge into one chip.
- **Colours tab in Settings**, and tabs that scroll on narrow windows.
- **macOS 27 support** — native comment bubble suppressed, note-box text stays sharp when zoomed.

## Margin comment indicators

Every highlight, underline and strike-out carrying a comment now shows a dot in the right margin, tinted to the annotation's colour.

- **Clustered by line.** Up to three comments on a line overlap as a stack; four or more collapse to a single dot with a count.
- **Hover to fan out; click to open** that comment for editing. Your previous tool is restored afterwards.
- **Mirrors the sidebar.** Dots reflect the annotation list's current filter, search and sort at once. Comments outside the filter dim to a faint, non-interactive layer instead of vanishing. With the list closed or unfiltered, every dot shows at full strength.
- **Settings → Annotation → Comments** — Margin, Size and Opacity, with a live preview and **Reset to Defaults**. Indicators can be switched off.

## Markdown export

- **File → Export Annotations as Markdown → All… / Currently Filtered…**
- Each entry is a blockquote of the marked passage, your comment beneath it, and a `Page · Colour · Type` tag. Entries are grouped by page.
- **Currently Filtered…** exports exactly what the sidebar shows, so a colour, search or type filter becomes the export scope.
- The same Markdown can go to the clipboard instead of a file.

## Copy as Clean Text (⌘⇧C)

Copies selected PDF text with its line breaks repaired.

- Joins wrapped lines into paragraphs, keeping real paragraph breaks.
- Removes hyphenation at line breaks (*anno-* + *tation* → *annotation*).
- Normalises ligatures (ﬁ → fi); curly quotes can be straightened.
- Each step is optional under **Settings → Annotation → Copying Text**.
- Plain ⌘C is unchanged.

## Formatting comments

- **⌘B** and **⌘I** toggle Markdown emphasis around the selection, or at the cursor.
- Markers stay visible: comments remain plain Markdown, including in the new export.
- Each toggle is a single undo step.

## Annotation navigation

- **⌥↑** and **⌥↓** move between annotations, advancing the sidebar selection and centring each one in the document.
- Follows the sidebar's current filtered and sorted order, falling back to document order when unfiltered.
- Yields to a focused comment editor, and stops at the first and last annotation rather than wrapping.

## Palette backup and share

- **Settings → Colours → Backup & Share** exports your six tool colours, nine Quick Colours and any colour names as a short code or a file.
- Importing shows a swatch preview and the number of colour names included, before anything is applied.
- Only your defaults change — documents already open keep their own colours.

## Colour filter

- Colours differing only by rounding or colour space now merge into one filter chip instead of two.
- Colour matching is consolidated in a single place, so the filter, the list and the margin dots agree.

## Settings

- **New Colours tab** — default colours, Quick Colours, presets and palette sharing.
- Tabs scroll when the window is too narrow to show them all.
- Sliders track the pointer continuously instead of snapping between steps.

## macOS 27

- **Native comment bubble suppressed.** macOS 27 attaches its own bubble to commented markup, opening its own editor. The margin indicators serve the same purpose, so Angora hides it.
- **Note boxes stay sharp.** Annotation text was being rasterised at a fixed resolution and scaled up, leaving it soft on Retina displays and coarse when zoomed. It now redraws at the display's own resolution.

Both apply only on macOS 27; earlier systems are unchanged.

## Fixes and refinements

- Dragging the annotation list's sort tabs and colour chips now works on macOS 14 and 15, not only macOS 26 and later.
- The window subtitle now derives directly from the document's page state.
- Localisation covers the new comment-indicator controls in all five languages.

## Updating

If you are already running Angora, choose **Check for Updates…** and Sparkle will offer 1.1.4 (Smoke Pearl). Otherwise, download the latest `.dmg` from the [Releases page](https://github.com/j-nivekk/Angora-Beta/releases), open it, and drag Angora into your Applications folder.

The Beta is signed with an Apple Development certificate but is **not notarised by Apple**, so macOS Gatekeeper will block it on first launch. You only need to do this once:

- **Recommended.** Control-click **Angora Beta** in Applications → **Open** → **Open**.
- Or, after a blocked attempt, open **System Settings → Privacy & Security** and click **Open Anyway**.
- Or, from Terminal: `xattr -cr /Applications/Angora\ Beta.app`.

## System requirements

- macOS 14 (Sonoma) or later
- Apple Silicon or Intel
